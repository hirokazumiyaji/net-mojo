# net-mojo v0.2.0

Release notes for the next minor tag. Publish this file as the GitHub Release
body when tagging `v0.2.0` (see README "Versioning and compatibility").

## Highlights

- HTTP/1.1 origin server with optional TLS, trailers, detach / streaming
  responses, request-body streaming, ServeMux routing, middleware, handler
  offload, CONNECT / Upgrade hijack, and WebSocket (RFC 6455).
- Optional HTTP/2 and HTTP/3 servers (feature environments), including
  multiplexed detach / streaming responses and request-body streaming.
- Synchronous HTTP/1.1 `Client` with redirects, pooling, and verified HTTPS.
- Static file serving (`FileServer`) and optional gzip response compression.
- Multi-worker `ServerPool` on a shared listener, plus continuous dogfood
  service example.
- Conda publish on `v*.*.*` tags, fuzz / property-test CI, and sanitizer
  coverage across supported platforms.

## Requirements

- Mojo 1.1.0 (core package; pinned in `pixi.toml` and `conda.recipe`).
- Platforms: Linux x86_64, Linux aarch64, and macOS arm64.
- Optional TLS / HTTP/2 / HTTP/3 / compression providers remain feature
  environments and are not part of the core conda package.

## Install

After the tag is published to the configured prefix.dev channel:

```sh
pixi add net-mojo -c <PREFIX_CHANNEL>
```

Or download the platform `net-<platform>.mojoc` artifact from the GitHub
Release and rename it to `net.mojoc` on the import path.

See [CHANGELOG.md](../../CHANGELOG.md) for the full list of changes moved
under `## [0.2.0]` when the tag is cut, and [SECURITY.md](../../SECURITY.md)
for supported versions and private vulnerability reporting.
