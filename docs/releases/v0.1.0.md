# net-mojo v0.1.0

Released September 6, 2026.

The initial release provides synchronous IPv4 and IPv6 addressing, OS name
resolution, TCP, UDP, and Unix stream sockets. Socket operations use explicit
deadlines and move-only descriptor ownership. Single-threaded `Poller`
multiplexing and thread-based cancellation through shutdown are included.

Supported platforms are macOS arm64, Linux x86_64, and Linux aarch64.
The attached `net.mojoc` artifact was precompiled with Mojo 1.0.0 and requires
that compiler release. Put the artifact's directory on the import path with
`mojo run -I <dir> your_program.mojo`.

For source builds, check out the `v0.1.0` tag and run `pixi install --frozen`.
Release versions follow Semantic Versioning, with `pixi.toml` as the version
source of truth. Public API includes names reachable from `net` without a
leading underscore; `net/_sys/` and names starting with `_` are internal.

HTTP servers, TLS, HTTP/2, and HTTP/3 were added after this release.

See the [original GitHub Release](https://github.com/hirokazumiyaji/net-mojo/releases/tag/v0.1.0)
for the published artifact and the [changelog](../../CHANGELOG.md) for changes
since this release.
